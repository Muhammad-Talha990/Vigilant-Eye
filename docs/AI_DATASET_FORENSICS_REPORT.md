## 13. Manual annotation requirements

**Must annotate before any serious retrain:**

1. CCTV stills: phones, watches (smart vs normal), notes/chits, gadgets — prioritize frames where objects are visible.  
2. Cheating videos: sparse sampled frames for OD; full clips labeled with **activity intervals** for temporal tasks.  
3. Large set of **negatives** (clean desks, answer sheets only).

**Tooling recommendation:** CVAT (video + boxes + attributes) or Label Studio; LabelImg acceptable for stills-only.

**Box rules (summary):**
- Tight boxes on device/note; include partially visible ≥30% if identity clear.  
- Tiny distant phones: annotate if ≥~12 px; else skip or mark difficult.  
- Do not box monitors/bags as gadgets.  
- Answer booklets ≠ `notes_paper` unless clearly unauthorized chit.  
- Occlusion: annotate visible portion.  
- QA: second reviewer on ≥10% + all rare-class images.

## 14. Train / val / test split strategy

1. Build `source_key` per image (`session_aware_split.py`).  
2. Assign each key wholly to train/val/test (e.g. 80/12/8 by session, not by frame).  
3. Stratify rare classes (phone/watch) across splits at session level.  
4. Hold out entire cameras/rooms when possible for test.
